遊戲規則說明
  1. 共 {{ state.max_turns }} 回合，兩位玩家在同一台機器上輪流。
  2. 每位玩家前 {{ opening_moves_per_player }} 手是「開局階段」：直接點中立 POI 佈子，不畫路線、不翻面。
  3. 開局佈完後進入連線回合：先點自己的 POI 當起點，再點中立 POI 連線過去。
  4. 後端用 OSRM 算起點到目標的步行路線；超過 {{ max_walk_seconds // 60 }} 分鐘（{{ max_walk_seconds }} 秒）無效。
  5. 合法時目標 POI 一定變成你的。
  6. 沿著路線畫 {{ buffer_normal_m }}m 影響範圍：
    • 範圍內若有任何中立 POI → 路線被阻斷，只翻目標。
    • 範圍內沒有中立 POI → 所有對手 POI 都翻給你。
  7. 無路可走時可以跳過本回合；連續兩次跳過結束遊戲。
  8. 分數即時依目前 POI 擁有者計算，相同則平手。
